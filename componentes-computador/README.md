# Componentes de um Computador

Ontologia (OWL) desenvolvida para a disciplina de Web Semântica, modelando
componentes de hardware de um computador.

## Conceito

Modela componentes (armazenamento, periféricos, softwares) e suas relações,
  como containsSoftware, enablesPeripheral, cools, powers,
  supportsOutputDevice e authenticatesOn.
